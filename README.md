Исходники опубликованы с целью самостоятельного ознакомления с игровым модом 2013 года, перенесённым под SAMP 0.3.7/OPEN.MP. Баги и прочие ошибки мода не были исправлены, были внесены лишь небольшие изменения, мод не рассчитан на полноценное открытие из-за чего сервер может работать нестабильно и могут вылезти ошибки из-за переноса мода под современную версию мультиплеера.
