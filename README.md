# MyGame World
Легендарный SA:MP проект 2010-2016 годов, основанный на исходниках SenseGame<br>
Версия игрового мода - v3.8.3 (Исходник 2013 года)<br>

<img width="640" height="360" alt="IwKes2gwt39DGQTCi-wWB4As2rSJsq510GkoiNWeScpwh_l_D58uztNLHcgXdcNcwPBU8MUB" src="https://github.com/user-attachments/assets/e366d869-9426-45ab-9df4-ddd350d2402e" />

Исходники опубликованы с целью самостоятельного ознакомления с игровым модом 2013 года, перенесённым под SAMP 0.3.7/open.mp. Баги и прочие ошибки мода не исправлялись, были внесены лишь небольшие изменения, не меняющие суть проекта.<br>

Мод не рассчитан на полноценный запуск сервера, поэтому он может работать нестабильно, а также могут возникнуть ошибки, связанные с переносом мода на актуальную версию мультиплеера.


# Примечание
Для удобства ознакомления была создана команда для выдачи стартового набора - /test<br>
Вы получаете игровую валюту, донат валюту, максимальный уровень админ-прав, 50 уровень персонажа, мед.карту и полный пакет лицензий.
